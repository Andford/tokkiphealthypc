# Tokkip Healthy PC

Tokkip cuida tu PC. Revisa lo que ya no sirve —temporales, cachés de
navegadores y apps, volcados de errores, la papelera—, te deja elegir qué se
va y lo limpia, sin forzar nada que esté en uso. En Inicio te dice cómo se
siente tu PC y por qué.

Todo se queda en tu PC: sin cuenta, sin nube, sin telemetría.

Esta es la versión nueva, hecha de cero con Tauri. Lo que falta para que
reemplace a la anterior está en [docs/PLAN.md](docs/PLAN.md).

## Desarrollo

```
npm ci
npm run tauri dev
```
